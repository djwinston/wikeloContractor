Ordinary mining. Wikelo asks for the **refined** commodity, while the deposits yield the raw ore, so a
run is mine → refine → hand in. Deposit locations and refinery prices are tracked at
[sc-trade.tools](https://sc-trade.tools/) and [UEX](https://uexcorp.space/).
